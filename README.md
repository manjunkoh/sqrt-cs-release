# Square Root-Factorized Covariance Steering

This repository contains the code for the paper "Square Root-Factorized Covariance Steering".

## Dependencies

- MATLAB
- YALMIP
- MOSEK

## Usage
The three scripts in the top level directory reproduce the numerical results in the paper.
